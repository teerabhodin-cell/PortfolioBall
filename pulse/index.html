# เพิ่มห้องแชต (Team space)

กรอกข้อมูลเพื่อเพิ่มห้องใหม่ลงฐานข้อมูล Cloud

▣ เพิ่มโปรเจกต์

กรอกข้อมูลเพื่อเพิ่มโปรเจกต์ใหม่ลงฐานข้อมูล Cloud

✓ เพิ่มงาน (Task)

งานที่เพิ่มที่นี่จะ sync ไปหน้า My tasks ของทุกคนแบบ realtime

▤ เพิ่มไฟล์

กรอกข้อมูลไฟล์ที่ต้องการแชร์ให้ทีม (ลิงก์ดาวน์โหลดสามารถใช้ Firebase Storage หรือ URL ใดก็ได้)

◍ เพิ่มสมาชิกทีม

กรอกข้อมูลสมาชิกใหม่ในทีม DevSphere
